# The Funniest Sick-Day Excuse

One line, under 200 characters, that gets you out of work and gets a laugh.

## The line

> Sorry, can't come in today — I threw my back out reaching for the snooze button, and now the floor and I are in a committed relationship.

## How it works

`main.py` (Python standard library only, deterministic) writes that single
line to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
